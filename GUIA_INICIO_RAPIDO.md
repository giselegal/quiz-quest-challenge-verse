# 🚀 GUIA DE INÍCIO RÁPIDO - QUIZ QUEST CHALLENGE VERSE

## ⚡ **EM 5 MINUTOS VOCÊ ESTARÁ CRIANDO QUIZZES PROFISSIONAIS!**

### 🎯 **Passo 1: Acessar o Editor**
```
🌐 URL: http://localhost:8080/editor
```
Clique e acesse o editor revolucionário!

### 🎨 **Passo 2: Escolher um Template**
1. Clique no botão **"🎨 Templates"** na toolbar
2. Escolha um template que combina com seu objetivo:
   - 🎯 **Quiz de Personalidade** - Para engajar audiências
   - 📊 **Pesquisa de Mercado** - Para coletar insights
   - 🎓 **Quiz Educacional** - Para ensinar e testar
   - 💼 **Lead Generation** - Para capturar leads
   - 🎮 **Quiz Gamificado** - Para entreter

### 🧩 **Passo 3: Personalizar Componentes**
**Use a Sidebar à Esquerda:**
- ❓ **Pergunta** - Arraste para criar perguntas
- 📝 **Texto** - Adicione explicações
- 🖼️ **Imagem** - Inclua visuais
- 🔘 **Botão** - Configure ações
- 📋 **Formulário** - Colete dados

**Configure no Painel Direito:**
- Altere textos, cores e estilos
- Defina ações e navegação  
- Ajuste propriedades específicas

### 💾 **Passo 4: Salvar Automaticamente**
✅ **Não se preocupe!** O auto-save está sempre ativo:
- 💾 Salva a cada 2 segundos
- ✅ Mostra status na toolbar
- 🔄 Tem backup automático

### 👁️ **Passo 5: Visualizar**
- Clique em **"👁️ Preview"** para ver como ficou
- Teste a navegação e interações
- Ajuste conforme necessário

---

## ⚡ **ATALHOS ESSENCIAIS**

| Atalho | Função |
|--------|--------|
| `Ctrl + Z` | Desfazer última ação |
| `Ctrl + Y` | Refazer ação desfeita |
| `Ctrl + S` | Forçar salvamento |
| `Del` | Deletar componente |
| `Ctrl + D` | Duplicar componente |

## 🎯 **EXEMPLOS PRÁTICOS**

### **Criar Quiz de Personalidade em 3 Minutos**

1. **Escolher Template**
   - Abra galeria de templates
   - Selecione "Quiz de Personalidade"
   - Clique em "Clonar"

2. **Personalizar Conteúdo**
   - Mude o título principal
   - Edite as perguntas
   - Ajuste as opções de resposta
   - Defina resultados possíveis

3. **Configurar Design**
   - Escolha cores no painel
   - Adicione imagens relevantes
   - Ajuste fontes e espaçamentos

4. **Testar e Publicar**
   - Use preview para testar
   - Compartilhe via URL
   - ✅ Pronto!

1. **Template Lead Generation**
2. **Adicionar Formulário**
   - Nome, email, telefone
   - Campo de interesse
3. **Configurar Entrega**
   - Página de agradecimento
   - Email automático
4. **Publicar e Capturar Leads**

## 🔧 **SOLUÇÃO DE PROBLEMAS**

### **❓ Quiz não salva?**
✅ Verifique conexão com internet  
✅ Observe status de auto-save na toolbar  
✅ Use Ctrl+S para forçar salvamento

### **❓ Componente não aparece?**
✅ Verifique se está na etapa correta  
✅ Use painel de propriedades  
✅ Teste no modo preview

### **❓ Performance lenta?**
✅ Ative monitor de performance  
✅ Siga sugestões de otimização  
✅ Reduza número de componentes

### **❓ Não consigo colaborar?**
